Detour Car Rental — local HTML demo

1. Extract the entire ZIP to a folder.
2. Open index.html in Google Chrome. Keep the HTML, CSS, JS and assets together.
3. Start at Explore and choose Plan this drive, or go straight to Find a car.
4. Compare cars in the fleet and confirm with sample driver details.
5. Open My booking to edit or cancel your most recent demo reservation.
6. Check the pick-up guide from the confirmation or from My booking.
7. Open Trip pack and choose Print or save PDF for an offline copy.

The site runs offline. No installation or build command is needed. Use one browser
to keep your demo profile, trip, and most recent reservation between pages.
If your browser isolates local files or blocks local storage, use Chrome with
local storage available or serve the extracted folder from a static web server.

Demo profiles use a name and email, with no password or identity verification.
Use sample information. Rates, luggage capacities, pick-up locations and reservations
are illustrative. Availability uses a sample weekly pick-up schedule. For example,
The City is unavailable on Fridays. Real branch addresses, hours, and operator policies need to be
provided for a live site. The site has no live inventory or payments.

Page files
  index.html          Landing page and trip planner
  fleet.html          Fleet catalog and transmission filters
  car.html            Car details, opened from the catalog
  compare.html        Compare cars and estimated trip totals
  explore.html        Scenic drive catalog
  route.html          Drive itinerary with Plan this drive
  locations.html      Sample pick-up locations
  pickup-guide.html   Branch guide and pick-up checklist
  faq.html            Rental questions and sample policy guidance
  sign-in.html        Open a local demo profile
  sign-up.html        Create a local demo profile
  booking.html        Review trip, driver details and estimated total
  confirmation.html   Demo booking reference and receipt
  trip-pack.html      Printable reservation, checklist, and selected itinerary
  my-booking.html     View, edit, or cancel the most recent demo reservation

Theme colors are defined near the top of site.css. The sample fleet and locations
are defined in site.js. Photos and fonts are stored in assets/.
